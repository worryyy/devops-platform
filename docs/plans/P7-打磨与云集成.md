# P7 · 打磨与云集成（持续）

> **目标**：权限/审计/审批/多环境补齐平台"运营"属性；服务自助接入把
  onboarding 成本降到分钟级；阿里云 OpenAPI 三件套（ECS/ACR/OSS）让平台
  看得见云资源与成本。
> **工期**：持续（每项独立可排期，按需取用）。
> **前置依赖**：P2/P3/P6 已交付的模块。
> **蓝图引用**：§7.8 阿里云集成、§9 仓库结构、§5 取舍表 #12；
  backlog 项（根因 agent、span 自研页）也登记在此。
> **状态**：⬜ 未开始

## 1. 任务清单（按独立条目排期）

### 1.1 RBAC 与审计
- [ ] `migrations/009_rbac.sql`：`roles(id, name, permissions jsonb)`、
      `user_roles(user_id, role_id)`；权限点枚举：
      `pipeline:trigger / pipeline:revert / service:write /
      alert:ack / inspection:run / report:trigger / user:manage`
- [ ] JWT claims 带 role；gin 中间件按权限点校验（替换 P1 的
      粗粒度 admin/viewer）；前端按钮级权限控制
- [ ] `migrations/010_audit_logs.sql`：`audit_logs(id, user_id, action,
      target, detail jsonb, ip, created_at)`；所有写操作中间件落审计

### 1.2 发布审批工单
- [ ] `POST /api/pipelines/:id/approval`：高危服务（可配置名单）触发
      前进入 `pending_approval`，admin 批准后才调 Jenkins；
      pipeline_runs 状态机扩展；前端审批队列页；审批记录入 audit_logs

### 1.3 多环境
- [ ] catalog environments 支持第二环境（如 `staging`）：values 文件
      与 Argo Application 模板化生成（GitOps PR）；P2 触发参数
      TARGET_ENV 下拉来自 catalog；流水线 wait-for-release 复用
      （已按 catalog 驱动，无代码改动，仅配置）

### 1.4 服务自助接入（onboarding）
- [ ] `POST /api/onboarding/service` {name, displayName, owner,
      profile 默认值, ingressPaths}（权限 service:write）：
  1. services 表登记（source=api）
  2. 生成 workload values 文件（模板渲染 go-service values）并提
     GitOps PR（GitHub API，分支 `onboarding/<service>`）
  3. 生成 Argo CD Application YAML（同 PR）
  4. 返回清单：PR 链接 + 待办（业务仓 Dockerfile/Jenkins job 参数
     确认）
- [ ] 前端 `/onboarding` 向导页（表单分步 + 提交后状态跟踪）
- [ ] 验收口径固定：新服务从提交到 Argo Application Healthy ≤10 分钟

### 1.5 阿里云 OpenAPI（alibabacloud-go v2）
- [ ] `internal/cloud/`：凭证走 `ALIBABA_CLOUD_ACCESS_KEY_ID/SECRET`
  （RAM 子账号最小权限：ECS 只读、ACR 指定命名空间读写、OSS 指定
  bucket；Secret 注入，AK 不落库不进镜像）
  - `ecs.go`：DescribeInstances（本账号实例：规格/状态/到期/内网 IP）
  - `acr.go`：仓库列表、tag 查询、tag 清理规则
  - `oss.go`：对象上传/列举（备份归档直传）
  - `bss.go`（可选）：周成本查询
- [ ] 平台页面：`/cloud` 资源页（实例卡片：到期/状态告警色）+
  `制品管理`页（ACR repo/tag 表，tag 一键清理）
- [ ] 巡检接入：`instance_expiry`（ECS 到期 <7d warn）、
  `acr_quota`（仓库数/配额水位）两个新检查器
- [ ] 备份异地化：pg-dump CronJob 增加双写 OSS（跨集群容灾语义）；
  周报加「本周云成本」栏（bss）
- [ ] 平台资源页与 CMDB 关联：实例 ↔ 节点 ↔ 服务三条链（labels
      node 对映 inventory）

      干扰（catalog/TARGET_ENV 驱动）
